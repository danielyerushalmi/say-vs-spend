- `spearman`: rank agreement, 1 = same order, 0 = no relation, -1 = reversed. Wobble = middle 90% of a bootstrap over brands. `could_be_chance` = wobble range crosses 0.
- `trust_card.verdict` is set by CODE from thresholds written in decisions.md BEFORE results (`intent` Spearman >= 0.7 trust, 0.4-0.7 double-check, < 0.4 ask real people).
- Optional BUY fields (present only when the Flashpoint export has BUY__ columns; absent or null otherwise):
  - `questions.buy`: `{"text": "Is this a kind of product you buy?", "scale": "yes/no"}`.
  - `brands[].buy_share`: share of personas answering yes (0-1). `brands[].niche`: true when `buy_share` is strictly under 0.30 (exactly 0.30 is not niche).
  - `brands[].labels.buy`: same crowd label as the others (`SYNTHETIC`, or `FAKE TEST DATA` in sample mode).
  - `agreement_buyers`: `{"intent": {same keys as agreement.intent}, "n_brands": 0, "min_yes_respondents": 10}`, or `null` with no BUY data. Intent mean uses only personas who said BUY = yes; brands with fewer than 10 such personas are left out of that ranking.
  - `limits[]` gains one line saying buyers-only is a secondary view, not the trust label. `trust_card` is unchanged (all-persona intent).
- `store` (only if built): `{"name", "description", "label": "FICTIONAL DEMO STORE", "say_mean", "intent_mean", "aware_share", "verdict", "note": "No answer key for this store; trust level comes from the brand test."}`
- Display words: Trust it / Double-check it / Ask real people. Every number shows its label.
