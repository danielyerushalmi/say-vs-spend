## What it does

Say vs. Spend asks a free AI crowd of shoppers what it thinks of online brands, then checks that crowd against each company's real yearly sales and against a fame-only ranking, and ends with one plain label: Trust it, Double-check it, or Ask real people.

```
 [__] public, online-first brands (SEC 10-K annual reports)
        |
  Answer key: each company's yearly revenue   (MEASURED, SEC EDGAR)
        |
  Flashpoint AI crowd, one panel, order shuffled per respondent   (SYNTHETIC)
    - "Have you heard of this brand?"     -> fame baseline
    - "How good is this website? 1-10"    -> SAY
    - "How likely are you to buy? 1-10"   -> INTENT
        |
  Plain code: rank brands, Spearman agreement, wobble range
        |
  Claude: "detective" asks the crowd WHY on the biggest gaps   (AI-generated)
        |
  Trust card: label set by code from a rule written before results
        |
  Stopped for a human. Nothing was bought.
```

## Why it matters

A small online store cannot afford a real focus group. A free AI one is tempting, but nobody tells the owner how far to trust it. We do not claim the AI crowd is right. We test it on companies where an answer key exists (real sales), and say how far to trust it where no key exists.

## The headline question

**Did the AI crowd understand shoppers, or just pick the famous brands?**

We answer it with a fair comparison. Fame comes from the same panel (the share who say they have heard of each brand). The crowd "beats fame" only if its buying-intent ranking matches real revenue better than the fame ranking does.

## How we keep it honest

- **Pre-registered.** The trust rule was written in `decisions.md` (11:47 AM ET, Nov 14) before any panel result or comparison existed. Intent Spearman at least 0.7: Trust it. 0.4 to under 0.7: Double-check it. Under 0.4: Ask real people. If the 90% wobble range crosses 0, the label cannot be "Trust it." It is in the git history.
- **Fame baseline from the same panel.** No outside popularity list.
- **Randomized order.** Flashpoint shuffles the brand order per respondent, so first-shown does not win.
- **Wobble range.** We resample the brands 1,000 times [confirm count in say/compare.py] and show the middle 90%. A range crossing 0 is shown as "could be chance."
- **Every number is labeled:** SYNTHETIC (AI crowd), MEASURED (SEC filings), AI-generated (the detective's reasons), ESTIMATE (cost, predictions).
- **Label set by code,** not by a model. Models only write the explanation text.
- **All arithmetic is plain code.** Models do not compute results.
- **Human stop.** The trust card ends with "Stopped for a human. Nothing was bought."
- **One disclosed exception.** One company's revenue was seen during our SEC data test, before brand selection. We judged each brand's fame before looking up revenue [confirm this was done].

## Limits

- **Revenue is total yearly revenue,** including wholesale and worldwide sales, not website-only sales. It is the best public answer key, not a perfect one.
- **Both crowd answers are things people say.** Only revenue is real spending.
- **Small number of brands** ([__]). A small sample is why we show wobble ranges.
- **Fiscal years differ** between companies.
- **Persona model:** in this morning's runs, Flashpoint's persona answers were generated by "gpt-5.4-mini" and marked "uncalibrated" in Flashpoint's own run metadata. The crowd is synthetic and made by another vendor's model.
- A rating from 1 to 10 is a stated opinion, not a purchase.
- The "try your store" page uses a FICTIONAL DEMO STORE and has no answer key.

## No investment advice

This is a test of a survey method. It shows no stock tickers and no prices, and it says nothing about whether any company is a good investment.

## Reproduce it

Data note: SEC EDGAR company data (`data.sec.gov`) needs no key. Flashpoint has no API key: it uses a browser (OAuth) login, so all Flashpoint calls happen inside a signed-in Claude Code session over MCP and are saved to files that the Python reads.

1. Brand list and revenue: `say/brands/` [confirm file names].
2. Run the panel in Claude Code (Flashpoint survey tool, loop over brands, random order, export per-respondent CSV) into `say/panels/` [confirm].
3. Set `ANTHROPIC_API_KEY` in your own terminal (never in a file). Run the comparer and detective: `python -m say.compare` [confirm command].
4. Open the page in `frontend/` on the saved run file.

Tests: `python -m pytest say/tests` [confirm].
